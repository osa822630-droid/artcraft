# ArtCraft Creative Studio

ArtCraft Creative Studio helps you turn visual ideas into clear prompts and practical production plans for the ArtCraft desktop app. It includes focused skills for still images, video, and 2D/3D scene planning. Ask Claude for an ArtCraft-ready prompt, attach a reference image when relevant, and copy the result into the matching workflow in ArtCraft.

## Included skills

- **ArtCraft Image Prompting** — text-to-image, reference-led edits, compositing, and masked inpainting.
- **ArtCraft Video Prompting** — image-to-video and video-shot prompts with clear subject and camera motion.
- **ArtCraft Scene Planning** — 2D/3D layouts, locations, character posing, props, mesh briefs, and shot plans.

## What this plugin does

This is a prompt-writing and planning aid. It does not launch or control ArtCraft, generate media, or connect to an ArtCraft account. It contains no MCP connector, executable scripts, API keys, or hooks, and it does not send your prompts or reference images to ArtCraft. You run the relevant generation or editing workflow yourself in the ArtCraft app; model availability and controls are determined by the app's current model picker.
